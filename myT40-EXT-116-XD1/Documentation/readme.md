Modification of existing original local extension unit LE-116-XD1.

Documentation found in document for myT40-PLC chapter 14.

Keep in mind, that this reflects a modification of an original LE-116-XD1 module.
This is the description how to connect this 16-Output module to myT40-PLC using the modified extension slot.
To make this possible, the existing header PCB must be exchanged by this one decribed here.

Original extention modules must not connect to myT40-PLC, due to different and unknown protocol and connectivity.
